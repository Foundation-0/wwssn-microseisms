# Station selection and sampling audit

Status: preparation for review. No observational result is claimed.

The proposed screen requires three complete calendar years, at least ninety percent of days and no missing run longer than seven days. These thresholds are proposals to freeze before inspecting the real inventory. Calendar leap days, duplicate scans and missing dates must be handled explicitly.

Apply the same screen to every candidate start year for every station, and report all windows rather than choosing only the most favourable one. Input station-days need listing provenance; a scan count is not a count of distinct days. If no station passes the frozen criterion, follow the project's stop rule.

For the earthquake-selection audit, use a versioned earthquake catalogue and freeze magnitude, distance and time-window definitions before comparing available and absent days. Compare coverage near events to coverage away from them while controlling station and calendar period. Report association and uncertainty; selection intent cannot be inferred from correlation alone.

No station passes or fails until the real listing is supplied. The code tests the criterion, not the representativeness of the released five-percent sample.
